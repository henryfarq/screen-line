# Screen Line

A Mac app that hangs every screenshot and screen recording on a line just
above your screen. Click one to copy it, hold it to mark it up, drag it into
any app or folder.

Based on [Tendedero](https://github.com/alejandrobujan/tendedero) by
Alejandro Buján, used under the MIT license (see `LICENSE`).

## Build

```
scripts/build-app.sh
open build/ScreenLine.app
```

Needs macOS 14 or later and the Xcode Command Line Tools.
